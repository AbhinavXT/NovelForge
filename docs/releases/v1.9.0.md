Sources are now plugins. Every source NovelForge reads from is a small script that can be updated on its own, so when a website changes, the fix reaches you without waiting for a new version of the app. Your library is unchanged: novels keep their source, reading progress and bookmarks.

Source plugins (Settings → Source plugins) - see which sources are installed, remove the ones you don't use, add plugin repositories, or install a plugin from a file. NovelForge's own plugins keep themselves up to date from the official repository (github.com/AbhinavXT/NovelForge-plugins).

Fixed: PawRead novels wouldn't open (the site moved to www.pawread.com).

Fixed: WuxiaClick showed nothing after the site's redesign. Rewritten for the new site, with genre, tag and sort filters, and chapter lists that include the newest chapters.

Fixed: Light Novel Translations lists and search were empty.

Fixed: Primordial Translation's list showed a "Text Mode" entry that wasn't a novel.

WTR-Lab: updated for the site's new chapter API. After a number of chapters the site asks for a human-verification step, which NovelForge can't do yet; chapters stop loading until then.

AllNovel, Graycity and LightNovelWorld: their sites are gone. If you're updating, they stay installed so their novels keep their place in your library; new installs don't include them.

This is also the first release built as a release build rather than a debug build. It is signed with the same key as before and installs over 1.8.1.
