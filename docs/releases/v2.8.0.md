A smaller app with the same sources.

Built-in sources: Royal Road, Primordial Translation, WTR-Lab and WuxiaClick ship with the app. The rest install from the official plugin repository under Settings → Source plugins.

If you're updating, nothing changes for you: sources you already have stay installed and keep updating, and your books, progress and backups from them work as before.

License: NovelForge is now under the MIT license. Releases up to 2.7.x remain under GPL-3.0.

Also: sites behind Cloudflare go through a rewritten check.

Installs over 2.7.0 as a normal update.
