Archive imported books to free up space. An imported book is stored in full, which comes to roughly one and a half times the size of its file. If you keep that file on your device anyway, that's a second copy. Archiving drops the stored text and reads it from the file again when you open the book. Your reading progress, bookmarks, highlights, notes, categories and stats stay as they are.

Archive one book: Library → long-press the book → Archive (free up space). Archived books get a small badge on their cover. Opening, exporting or listening to one restores it automatically, or use Restore from file in the same menu.

Archive all imported books: Settings → Storage → Archive all imported books. It works through your imported books one at a time, can be stopped at any point and picked up again later, and ends with a summary. Before archiving a book it checks that the file still reads back as exactly the same text, so your bookmarks can't move. Books whose file is missing or has changed keep their text.

Storage settings show how big the library database is and how much space can be reclaimed. Compact gives that space back to your device. Archive all compacts automatically when it finishes.

Library folder: a new "Import new books archived" switch brings books in from a scan with their chapter list, cover and details, but leaves the text in the file until you open the book. Useful for folders with hundreds or thousands of books.

If an archived book's file has moved, opening the book offers Locate file so you can point NovelForge at the new location.

Books imported by hand before NovelForge remembered where files came from can't be archived yet. Importing the same file again links it to the existing book, without touching your progress, and makes the book archivable.

Backups don't include the text of imported books. Restoring one brings those books back archived, and they read their text from the file if it's still on the device.

Installs over 2.0.0 as a normal update. Coming from 1.9.0 or older, follow the reinstall steps in the 2.0.0 release notes first.
