⚠️ This update needs a reinstall. Back up first.

NovelForge is now signed with a proper release key instead of the development key earlier versions used. Android only installs an update signed with the same key as the app already on your phone, so 2.0.0 can't install over 1.9.0 or older ("App not installed" / "package conflicts"). This is a one-time change: updates after 2.0.0 install normally again.

How to update without losing your library:

1. In your current NovelForge: Settings → Backup & Restore → Create backup. Save the file somewhere outside the app, such as Downloads.
2. Uninstall NovelForge.
3. Install NovelForge_v2.0.0.apk from this release.
4. Open it, go to Settings → Backup & Restore → Restore, and pick the backup file.

The backup brings back your library (including downloaded chapters and imported books), reading progress, bookmarks and highlights, reader and text-to-speech settings, your pronunciation dictionary and reading stats.

Not in the backup, so redo these after restoring:
- App theme and font (Settings → Appearance)
- Library folder: point NovelForge at it again (the folder and its files are untouched)
- Downloaded voices for neural text-to-speech
- Plugin repositories or plugins you added yourself (the built-in sources come back on their own)
- Covers of books you imported from files may be blank; re-importing a book brings its cover back

Audio you exported stays in your Music folder.

Everything else is the same as 1.9.0: sources are plugins that update on their own, plus the PawRead, WuxiaClick, Light Novel Translations and Primordial Translation fixes. See the 1.9.0 release notes for details.
