A better first five minutes.

Welcome: a fresh install opens with a welcome screen. Tick the sources you want from the official repository (the ones that used to come built in are ticked for you) and install them in one go, or import a book or restore a backup straight away. Skip is always there. Updating doesn't show it.

Guide: "How it works" on the welcome screen, or Settings → Reading → Guide, says where every feature lives.

Tips: a short tip appears once beside things that are easy to miss: searching your sources, searching inside books, highlights, vocabulary, the character codex, downloads, audio export, reading stats, character voices and source plugins. One shows at a time. Settings → Reading → Show tips again brings them back.

Installs over 2.8.0 as a normal update.
