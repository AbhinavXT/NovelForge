A better first five minutes.

Welcome: a fresh install opens with a welcome screen. Tick the sources you want from the official repository (the ones that used to come built in are ticked for you) and install them in one go, or import a book or restore a backup straight away. Skip is always there. Updating doesn't show it.

Tips: a short tip appears once next to the character codex, downloads, audio export, reading stats, character voices and source plugins, one at a time. Settings → Reading → Show tips again brings them back.

Installs over 2.8.0 as a normal update.
